    Keyboard Controls

    Use these controls to complete the activity without a mouse.

    Key What it does
    Tab Move to the next control
    Shift + Tab Move to the previous control
    ↑ Increase the selected proportion by 1%
    ↓ Decrease the selected proportion by 1%
    → Increase the selected proportion by 1%
    ← Decrease the selected proportion by 1%
    Home Set the selected proportion to 0%
    End Set the selected proportion to its highest allowed value
    Space Select a meal or activate a focused button
    Enter Activate a focused button

    Tip: If your keyboard does not have Home or End keys, use the arrow keys to adjust the slider one step at a time.
